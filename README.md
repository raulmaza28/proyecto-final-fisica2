# 📊 Proyecto Final de Física 2

Hola Profesor. Para calificar este programa interactivamente sin necesidad de descargar nada en su computadora, puede crear su propio entorno virtual en la nube siguiendo estos sencillos pasos:

---

### 🛠️ Paso 1: Crear su propio Codespace
1. Diríjase a la parte superior de esta página y haga clic en el botón verde grande que dice **`<> Code`**.
2. Seleccione la pestaña que dice **Codespaces**.
3. Haga clic en el botón verde que dice **`Create codespace on main`**.
*(GitHub abrirá una pestaña nueva y configurará un entorno de Visual Studio Code en su navegador en aproximadamente un minuto).*

---

### 🚀 Paso 2: Ejecutar el programa en la consola
Una vez que el entorno haya cargado por completo, diríjase a la **Terminal** (la consola negra en la parte inferior de la pantalla) y ejecute los siguientes comandos uno por uno presionando Enter:

1. Ingrese a la carpeta del paquete:
   ```bash
   cd fase1proyectoFinalFisica/src/fase1proyectofinalfisica/
   ```

2. Compile el archivo principal:
   ```bash
   javac Fase1proyectoFinalFisica.java
   ```

3. Regrese a la carpeta de origen:
   ```bash
   cd ..
   ```

4. Ejecute el programa interactivo:
   ```bash
   java fase1proyectofinalfisica.Fase1proyectoFinalFisica
   ```

---

*Nota: Si prefiere calificarlo de forma local en su propia computadora, puede presionar el botón **Code** ➡️ **Download ZIP** y abrir el proyecto directamente en NetBeans o su IDE de preferencia.*
