### 🚀 ¿Cómo correr el programa una vez dentro?
Cuando se abra el entorno en su navegador, abra la terminal (consola negra de abajo) y ejecute estos tres comandos uno por uno presionando Enter:

1. `cd fase1proyectoFinalFisica/src/fase1proyectofinalfisica/`
2. `javac Fase1proyectoFinalFisica.java`
3. `cd ..`
4. `java fase1proyectofinalfisica.Fase1proyectoFinalFisica`
